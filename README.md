# Varshini M C — Portfolio

A responsive personal portfolio for Varshini M C, a B.E. Information Science & Engineering student (2023–2027) with a CGPA of 9.24.

## Run locally
Open `index.html` in a browser. This is a static site and does not require a build step or package installation.

## Deploy with GitHub Pages
1. Open the repository **Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then save.
4. Wait for GitHub Pages to publish the site.

## Sections
- Introduction and contact links
- About and education
- Technical toolkit
- Featured and additional projects with repository links
- Career direction

## Customise
Update the content and project links in `index.html`. The theme toggle supports light and dark modes and remembers the visitor's choice.
